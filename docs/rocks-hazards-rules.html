10. Rocks, hazards and rules

Everything that can hurt you, and the rules that tie it all together.

Learning intentions

  • understand the five rock types and how a random choice is made
  • understand the hazards and what each one does to a ship
  • know the rules for objectives, perks, scoring and wormholes
  • read a few more examples of conditionals and loops

Success criteria: I can…

  • explain what 'chance weight' means
  • describe three hazards
  • list the order of events when a level is finished

Rock types

A rock has a kind. The kind changes its colour and what happens when it breaks. In Expedition mode, each new rock picks its kind at random, but some kinds are more likely than others. Each kind has a weight. A bigger weight means more likely.

RockFrom levelChance weightWhat it does
Normal160Splits into two smaller rocks.
Ice214Shatters into three pieces instead of two.
Explosive310Blows up when destroyed. The blast hurts ships, aliens and other rocks, and can set off a chain.
Gold28Pays extra credits when you destroy it.
Metal412Armoured. It takes 3 hits from bullets before it breaks.

Objectives

In Expedition mode, the wormhole stays closed until the level's objective is done. This is a rule the game checks every frame.

ObjectiveHow it works
Collect crystalsFly through the crystals (4 + level ÷ 2 of them).
Rescue podsTouch the drifting pods (2 + level ÷ 3 of them).
Escort the freighterKeep a slow cargo ship alive for 35 seconds. If it is destroyed, the wormhole still opens, but with no bonus.
Destroy the mothershipOn every fifth level.

Perks

After every level in Expedition mode you pick one of three random perks. In multiplayer the game waits until both players choose (or 20 seconds pass).

PerkEffect
Firepower+20% weapon damage
Hull Plating+25 max health and repair 25
Overdrive Engines+12% speed and acceleration
Quick CycleAbilities recharge 20% faster
Tractor FieldPickups are drawn toward your ship
Scavenger+25% credits earned
ResupplyRefill all ammunition now
Barrier Cell+30 rechargeable shield

The rulebook

  1. Rocks hurt ships. Each hit costs hull strength, then you get a short grace period.
  2. Bullets break rocks and hurt aliens. Kills earn score and credits.
  3. A level is finished when a ship enters an open wormhole. Then every player moves on.
  4. The wormhole will not open until the objective is done, and (on boss levels) the Mothership is destroyed.
  5. A destroyed ship comes back at the start of the next level with half its hull. The game is over when all ships are destroyed.
  6. The map grows each level, and rocks, aliens and gravity get stronger.
  7. In Classic mode there are no hazards, objectives, new aliens, rock types or perks.

Try it: add a rock type

You can invent a rock kind using only the settings and one small code change:

  1. Add "slow" to "rock_types" in game/config.py.
  2. Add a colour for it to ROCK_TINTS in game/sprites.py.
  3. Add an if rock.kind == "slow": rule in _break_rock that gives the player a bonus.

Check your understanding

1. An ice rock of size 3 breaks. How many rocks does it become?
Three smaller rocks of size 2 (if there is room under the maximum).
2. If normal has weight 60 and gold has weight 8, which is more likely?
Normal rocks.
3. Why does an ion storm stop shields from recharging?
It is a rule: ships inside have jammed set to true, and the recharge code skips jammed ships.
4. What must happen before a wormhole opens on level 10?
The objective must be finished and the Mothership destroyed.
5. Which statement runs in an if / elif chain: all matching branches, or just the first?
Just the first one that is true.
