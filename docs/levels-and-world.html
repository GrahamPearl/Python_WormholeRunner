7. Levels and the world

How levels are built and how the game gets harder.

Learning intentions

  • see how a level is built from rules and numbers
  • understand how the game gets harder as levels go up
  • understand how a bigger map is created and how the camera zooms out
  • read a formula in code

Success criteria: I can…

  • explain how many rocks a level has
  • explain the job of the wormhole
  • predict the map size for any level

The goal of a level

In every level the aim is the same: survive, finish the objective, then fly into the wormhole. A wormhole appears at a random time and stays open for a few seconds. In Expedition mode it will not open until the objective is done. On every fifth level, a boss ship called the Mothership must be destroyed first.

Building a level

When a level starts, one method builds everything. Read it from top to bottom. It is a long list of steps, which is a great example of sequence.

Notice how the level number appears in formulas. Here is the rule for the size of the map:

world_scale = min(max_scale, 1.0 + growth_per_level * (level - 1))

With the default settings (growth 0.25, maximum 3.0), level 1 is 1.0, level 2 is 1.25, level 3 is 1.5, and so on, until it stops at 3.0 (level 9). min picks the smaller of the two numbers so the map never grows past the limit.

Difficulty goes up with the level

Three small numbers make later levels harder. For each level above 1, rocks are 8% faster and gravity is 10% stronger. There are more rocks, and later levels bring new aliens and hazards.

Zooming out: the camera

A bigger map would not fit on your screen, so the camera zooms out. At map size 2.0, the zoom is 1 ÷ 2.0 = 0.5, so everything looks half as big. The change is smooth, not sudden. Each frame the zoom moves a small part of the way to the target:

This is a classic trick called easing: value += (target - value) * small_number.

Try it: design a level

Pick level 6 in the table. How many rocks are there? Which aliens appear? Now open game/config.py and find the numbers "growth_per_level" and "extra_rocks_per_level". Change them, run the game and see if you were right.

Check your understanding

1. What is the map size at level 5 with default settings?
1.0 + 0.25 × 4 = 2.0 times the screen.
2. What does min(3.0, 4.5) return?
3.0, the smaller value.
3. Why must the camera zoom out when the map gets bigger?
The bigger map would not fit on the screen otherwise.
4. Which part of _start_level would you change to add more rocks per level?
The lines that work out target_rocks, or the extra_rocks_per_level setting.
5. What must happen on boss levels before a wormhole opens?
The Mothership must be destroyed.
