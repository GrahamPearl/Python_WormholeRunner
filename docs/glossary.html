Glossary

Words used on these pages.

Look here when you meet a word you do not know. Some words are te reo Māori: ākonga means learner and kaiako means teacher.

WordMeaning
ĀkongaLearner or student.
AlgorithmA set of steps to solve a problem.
AotearoaThe Māori name for New Zealand.
AttributeA variable that belongs to an object, such as health.
BearingA direction measured in degrees clockwise from up, like a compass.
BooleanA value that is True or False.
BroadcastA message sent to every computer on a local network.
ClassA blueprint for making objects.
ClientThe computer that joins and asks, in a network.
CollisionWhen two things touch.
CompositionA class that has other objects as parts (a Player has a Ship).
Conditional statementCode that chooses what to do, such as if/elif/else.
CSSThe language that styles web pages.
Delta time (dt)How long the last frame took, in seconds.
DictionaryA collection of key: value pairs.
EasingMoving a value a small step toward a target each frame so the change looks smooth.
EventSomething that happens that a program can react to, like a key press.
FrameOne picture in the game loop. About 60 are drawn every second.
FunctionA named, reusable block of code.
Game loopThe repeating cycle of read input, update, draw.
Hangarau MatihikoThe Māori name for Digital Technologies in the New Zealand Curriculum.
HTMLThe language that gives a web page its structure and content.
IndexA position number in a list, starting at 0.
InheritanceA class taking over the features of a parent class (an is-a link).
IterationRepeating steps, usually with a loop.
JSONA text format for saving data such as dictionaries and lists.
KaiakoTeacher.
ListAn ordered collection of items.
LoopCode that repeats: for or while.
MassHow much matter something has. Heavier rocks pull harder.
MethodA function that belongs to a class.
MixinA parent class made only to share a group of methods.
Modulo (%)The remainder after dividing. Used for wrap-around.
MutableAble to be changed after it is made (lists, dictionaries, sets).
ObjectOne thing made from a class.
ParameterAn input to a function.
PolymorphismDifferent classes responding to the same method name in their own way.
PredictionGuessing what will happen next, so the game feels quick.
ReferenceA name pointing to an object in memory.
SelectionChoosing between paths, using if.
SelfInside a method, the object the method is working on.
SequenceSteps done one after the other.
Server (host)The computer that runs the real game in a networked game.
SetA collection of unique items, with no order.
SnapshotA record of where everything is at one moment.
SpriteA picture that moves around in a game.
State machineA design where something is in one state at a time and changes state when something happens.
TupleA list that cannot be changed.
TypeThe kind of data, such as int, float, str.
VariableA name that points to a value.
ViewOne screen of the game, such as the menu or the hangar.
Wrap-aroundLeaving one edge of the map and reappearing on the opposite edge.
