1. Python basics

Variables, decisions and loops, using code from the real game.

Learning intentions

  • understand variables and different kinds of data
  • use if, elif and else to make decisions
  • use for and while loops to repeat things
  • write and use functions

Success criteria: I can…

  • explain what a variable is using an example from the game
  • read an if statement and say when each branch runs
  • say how many times a for loop will run
  • explain why a function is useful

Programs are instructions

A program is a list of instructions the computer follows in order. This is called sequence. There are two other big ideas: selection (making a choice) and iteration (repeating). Every program you will ever meet is built from these three ideas.

Variables: labelled boxes

A variable is a name that points to a value. In the game the ship has a health value. When it is hit, the health goes down:

health = 100        # make a variable
health = health - 25   # use it, then store the new answer

Selection: if, elif, else

A conditional statement lets the program choose. The ship's steering code asks four yes/no questions: "Is the left key down? Is the right key down?" and so on.

Look at this line: boost = cfg("ship.boost_multiplier") if boosted else 1.0. It is a short way to write "if boosted is true, use the boost number, otherwise use 1.0". This is called a conditional expression.

Comparing values

Use == to ask are these equal?, != for not equal, and <, >, <=, >= for sizes. Join conditions with and, or and not. A single = is different: it stores a value.

Iteration: loops

The for loop: repeat for each item

Every rock pulls on your ship with gravity. The game adds up the pull from each rock using a for loop:

You can also loop a set number of times with range. for _ in range(5): repeats five times. (The underscore _ means "I don't need the counter".) Loops can be nested (a loop inside a loop). The code that creates aliens does this: one loop for each kind of alien, and another loop for how many of that kind.

continue means "skip the rest of this go and start the next one". break means "stop the loop now".

Careful: endless loops

If a while condition never becomes False, the loop never ends and your program freezes. Always make sure something inside the loop changes the condition.

Check your understanding

1. What are the three big ideas every program is built from?
Sequence (steps in order), selection (choices with if) and iteration (repeating with loops).
2. In control_step, what happens if up is False?
The lines inside if up: are skipped, so the speed does not increase.
3. A for loop goes over 12 rocks. How many times do the lines inside it run?
12 times, once per rock.
4. Why does gravity_accel use a function instead of copying the code each time?
A function can be reused. If the rule needs fixing, you fix it in one place.
5. What is the difference between = and ==?
= stores a value in a variable. == asks whether two values are equal.
