Wormhole Runner: learn Python by exploring a game

A guide for ākonga (learners) in Years 9 and 10.

Nau mai, haere mai! This site teaches the basics of Python by taking apart a real space game called Wormhole Runner. You fly a ship, dodge rocks that pull on you with gravity, fight aliens, and escape through wormholes. Every idea on these pages is something you can find in the game's code.

Learning intentions

  • see how a real program is built from small, simple parts
  • learn selection (if), iteration (loops), variables and data structures
  • learn how classes and objects are used to design a program
  • link the code to ideas in maths and physics
  • connect programming to web development: this site is itself a web project

Success criteria: I can…

  • read a short piece of Python and explain what it does
  • change a number in the game's settings and predict what will happen
  • draw a class diagram for a part of the game
  • write a prompt that asks an AI helper for one feature, then test the result

How to use these pages

  1. Get the game running first. Follow the steps on the Teacher notes page (install Python, then run the launcher file for your computer).
  2. Read a page, then open the code. Each code box shows real code from the game. The View on GitHub link opens the same lines in the full file.
  3. Try the "Try it" boxes. They ask you to change a setting or a line and see what happens.
  4. Check your understanding. Click each question to reveal the answer after you have had a go.

Tip: how to read code

Do not try to understand every line at once. First read the names (like health or speed). Good programmers choose names that explain themselves. Then read the comments. Then work out the steps one at a time.

What you need

  • A computer with Python 3.10 or newer (Windows, Linux or Mac).
  • The game files. Use run_windows.bat or run_linux.sh to start it.
  • A text editor such as Visual Studio Code, Thonny or IDLE.

Two players on the same network can fly together. Only play with people you know, on your school or home network.
