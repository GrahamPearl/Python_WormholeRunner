8. Ships and credits

One class, many ships, and the money system.

Learning intentions

  • see how ships are described using data instead of lots of code
  • understand each ship's ability and how it is checked in code
  • understand shields, damage order and the credits economy
  • see how weapons are built from a few simple types

Success criteria: I can…

  • explain what makes a ship different from another
  • describe the order the game checks before it damages a ship
  • explain why credits are saved in a file
  • add a new ship to the game by editing the settings

Ships are data

There is one Ship class, but six different ships. How? Each ship is described by a dictionary of settings: name, price, hull strength, speed numbers, an ability, and its own weapon. The same class reads those numbers and behaves differently. This idea is called data-driven design.

Taking damage: the order of checks

When something hurts a ship, the game asks questions in a careful order. A Specter in hyperspace takes no damage. The Bulwark's shield soaks up damage before the hull does.

  1. Is the ship dead, phased out, invincible (power-up) or in its short grace period? Then no damage. The function returns False.
  2. If the ship has a shield with energy left, the shield absorbs the damage first.
  3. Any damage left over reduces the hull. If the hull reaches 0, the ship is destroyed.

Weapons

All the weapons come from four simple types. The type setting decides which code runs:

  • bolt: a shot that flies straight. (A shotgun is just several bolts at slightly different angles.)
  • homing: a bolt that steers toward a target.
  • mine: stays where it is and explodes after a fuse, or when something comes close.
  • pulse: an instant explosion around the ship.

Credits: the in-game money

Credits exist only inside the game. They are not real money and you can never buy them. You earn them by playing. Then you spend them in the Hangar.

Check your understanding

1. Why can one Ship class make six different ships?
Each ship's numbers and abilities come from a settings dictionary, so the same code gives different results.
2. What does or do in an if condition?
The whole condition is true if any part is true.
3. A Bulwark with 30 shield energy takes 40 damage. How much reaches the hull?
10. The shield absorbs 30 first.
4. Why does the hyperjump code try up to 60 times?
A random spot might be next to a rock or alien. It keeps trying until it finds a safe one.
5. Where are your credits saved, and why?
In profile.json, so they are remembered after you close the game.
